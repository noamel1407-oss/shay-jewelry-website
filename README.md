# SHAY JEWELRY — אתר תכשיטי שי

אתר תכשיטים יוקרתי עם תצוגת 3D של טבעות.

🌐 **אתר חי:** https://noamel1407-oss.github.io/shay-jewelry-website/

## תוכן

- `index.html` — דף הבית
- `images/` — תמונות
- `models/` — מודלים תלת-ממדיים (GLB)

## הרצה מקומית

פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
npx serve .
```
